# Even-parity action provenance audit

Date: 2026-10-22

Status: `PUBLISHED_TABLE_REPLAYABLE; METRIC_TO_ACTION_REPLAY_NOT_ESTABLISHED`

## Finding

The artifact `docs/status/even_parity_cubic_quadratic_action_independent_derivation_2026-10-21.md` publishes an 81-monomial angularly integrated coefficient and labels the coefficient and Euler–Lagrange system as derived. The available replay tool, `tools/replay_even_parity_action_table.py`, explicitly parses that published table and checks selected Hessian identities. It does not construct the metric-dependent inverse, Christoffel symbols, Riemann tensor, curvature operator, density, or the `epsilon**2` coefficient.

The separate derivation contract, `docs/status/GFE_EVEN_PARITY_FULL_QUADRATIC_DERIVATION_CONTRACT_2026-10-21.md`, requires those operations to be performed from the metric and explicitly prohibits using the cached table or axial normalization to construct the answer. Therefore the current replay is a table-consistency check, not the required independent derivation replay.

## Convention discrepancy

The contract defines the action using the ordinary six-dimensional matrix trace on representative bivectors. The normalization audit records an exact factor-eight difference between that trace and the existing axial-generator coefficient. This establishes a convention discrepancy; it does not establish which convention the intended physical action uses, and it does not justify silently rescaling the full 81-term table.

## Evidence currently supported

- The published table can be parsed and selected principal/Hessian identities can be checked from its printed terms.
- The background bivector operator and normalized (Y_{20}) integral have independent checks in the existing obstruction audit.
- The ordinary-trace versus unrestricted-contraction factor is eight for the stated antisymmetric-pair convention.

## Not established

- A clean executable derivation of the complete `epsilon**2` density from the specified metric.
- Exact spherical integration of every term generated by that density in a clean replay.
- Independent term-by-term comparison of all 81 published terms against a regenerated action.
- Four Euler–Lagrange equations generated from a cleanly regenerated action.
- Resolution of the intended physical normalization from the source action.
- Constraint propagation or a physical degree-of-freedom count.

## Required next artifact

Add a deterministic executable generator that starts only from the metric in the derivation contract, computes the inverse metric, connection, curvature and six-dimensional operator, extracts the exact `epsilon**2` coefficient, integrates the angular dependence, and writes canonical action/equation receipts. The clean replay must not import the published action table, the axial generator table, or the normalization ratio. Compare with the published table only after generating the independent result.
