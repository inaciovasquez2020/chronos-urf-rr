## Definition

Metric convention:
\(f=1-2M/r,\quad Y=\sqrt{5/(16\pi)}(3\cos^2\theta-1)\)
\(g_{tt}=-f(1+\epsilon H_0Y),\ g_{tr}=\epsilon H_1Y,\ g_{rr}=f^{-1}(1+\epsilon H_2Y),\)
\(g_{\theta\theta}=r^2(1+\epsilon KY),\ g_{\phi\phi}=r^2\sin^2\theta(1+\epsilon KY).\)

The curvature convention was selected by requiring the background six-dimensional operator on bivectors `(tr,tθ,tφ,rθ,rφ,θφ)` to be `diag(2M/r^3,-M/r^3,-M/r^3,-M/r^3,-M/r^3,2M/r^3)`. The operator entries are `R_ab{}^{cd}=g^{ce}g^{df}R_abef`; the action uses the ordinary six-dimensional matrix trace.
