\par\noindent\textbf{Mathematical correction (25 November 2026).} The proof's arbitrary-basis inference is invalid: a basis vector of a sum need not belong to any constituent subspace. Instead let $U_v=\iota_{v*}Z_1(B_R(v))$, choose a basis of each $U_v$, and extract a maximal independent subset of their finite union. This is a basis of $W=\sum_v U_v$, because the union spans $W$. Assign each chosen vector to a ball containing it. This proves the stated vector count when vertex repetitions are allowed. If distinct centers are required and $D=\max_v\dim U_v>0$, each center can support at most $D$ chosen independent vectors; hence at least $\lceil C_R(G)/D\rceil$ distinct centers occur. Selecting one assigned vector at each center gives independent vectors with distinct supporting centers. The stronger distinct-center count $C_R(G)$ is not established. In fact for $G=K_5$, $R=1$, the rank is six but there are only five vertices, so that count is false in general. Historical text follows; use the corrected statements above.\par


\section*{Definitions}

Let $G=(V,E)$ be a finite graph.

Define

\[
C_R(G)
=
\dim_{\mathbb F_2}
\left(
\sum_{v\in V}\iota_{v*}Z_1(B_R(v))
\right)
\]

where $\iota_{v*}$ embeds the cycle space of the ball $B_R(v)$
into the global edge space $\mathbb F_2^{E}$.

\section*{Lemma}

\begin{lemma}
If
\[
C_R(G) \ge \alpha |V|
\]
for some $\alpha>0$, then there exist vertices
\[
v_1,\dots,v_m
\]
with
\[
m \ge \alpha |V|
\]
such that the vectors

\[
z_i \in \iota_{v_i*}Z_1(B_R(v_i))
\]

are linearly independent in $\mathbb F_2^{E}$.
\end{lemma}

\begin{proof}

By definition

\[
C_R(G)=\dim_{\mathbb F_2}(W)
\]

where

\[
W=\sum_{v\in V}\iota_{v*}Z_1(B_R(v)).
\]

Thus $W$ contains a basis of size $C_R(G)$.

Each basis vector arises from some vertex ball
$B_R(v)$.

Select one vertex for each basis vector that generates it.
Let the selected vertices be

\[
v_1,\dots,v_{C_R(G)}.
\]

Then the associated vectors

\[
z_i\in \iota_{v_i*}Z_1(B_R(v_i))
\]

are linearly independent.

Since

\[
C_R(G)\ge\alpha|V|
\]

we obtain at least $\alpha|V|$ such vertices.

\end{proof}
